## About

Full Stack Developer focused on PHP and Laravel. I build applications with Livewire, MySQL, automated testing, and a focus on maintainable backend architecture.

My main project, MESA, is a production-deployed nutrition application featuring transactional data flows, 300+ automated tests, a reproducible nutritional-data pipeline, and Docker-based deployment with automated CI/CD.
